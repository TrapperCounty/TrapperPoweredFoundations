# Repository contents

Published by TrapperCounty for mod testing and source review. The repository includes the mod implementation, uncooked mod assets, development helpers, player documentation, and selected test evidence. Compiled installable packages are attached to GitHub Releases.

The proprietary Satisfactory game, custom Unreal Engine SDK, Wwise installation, compiler/toolchains, player saves, credentials, and generated build caches are not included. Obtain development dependencies through their respective authorized distributions. Third-party components retain their own terms. No new general-purpose open-source license is being selected by this publication.

The mod code and assets were developed with AI assistance and tested as described in docs/VALIDATION.md. Test counts are historical evidence, not a guarantee for every game version or multiplayer environment.
